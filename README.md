# Zomato Restaurant Analysis Dashboard

### 📊 Project Overview
Analyzed 9,500+ restaurant records across India to deliver insights on restaurant ratings, location performance, cuisine trends, and customer preferences for business growth.

### 🛠️ Tools Used
- **SQL:** Data cleaning, Joins, Aggregation for KPI calculation
- **Excel:** Data Cleaning, Pivot Tables, Power Query
- **Power BI & Tableau:** 6 Interactive Visuals, Slicers, KPI Cards
